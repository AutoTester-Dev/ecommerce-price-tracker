# E-commerce Price Tracker 🚀

A robust and lightweight web scraping tool built with Python to extract product details from an online e-commerce platform and export the structured data directly into an Excel (`.xlsx`) spreadsheet.

## 🛠️ Tech Stack
- **Python** (Core programming language)
- **BeautifulSoup** (HTML parsing and data extraction)
- **Requests** (HTTP requests handling)
- **Pandas & OpenPyXL** (Data manipulation and clean Excel export)

## 📌 Features
- **Automated Scraping:** Quickly extracts product titles, prices, and stock availability from target pages.
- **Data Cleaning:** Automatically structures raw HTML text into a clean, tabular format.
- **Excel Export:** Saves the final dataset neatly into an `.xlsx` file for business analysis and price tracking.

## 🚀 Getting Started

Follow these instructions to set up and run the project locally on your machine.

### Prerequisites
Make sure you have Python installed. You will also need the following libraries:

```bash
pip install requests beautifulsoup4 pandas openpyxl```

### How to Run
```bash
python ecommerce_scraper.py```
